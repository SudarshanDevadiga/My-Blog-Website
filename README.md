# 🌐 My Blog Website

Welcome to my personal blog website! This is a simple HTML & CSS project where I share my thoughts on web development, learning, and life.

## ✨ Features

- Responsive layout using CSS Grid
- Hero section with background image
- Interactive blog post cards
- Sticky sidebar with categories and recent posts
- Clean and minimalist design

## 🛠️ Technologies Used

- HTML5
- CSS3 (No frameworks or libraries)
